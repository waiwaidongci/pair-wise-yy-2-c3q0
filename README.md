# 赛鸽血统环号登记站 · 运输笼周转台

运行：

```bash
npm start
```

访问 `http://localhost:3024`。

## 功能

- 鸽只档案、血统查询、转让和归巢成绩记录。
- 运输笼周转：
  - 每只足环同一时间只能待在一个笼位；装鸽前校验足环是否已在其他笼。
  - 换笼记录时间与经办人，原笼自动进入「待消毒」。
  - 卸鸽后笼位进入「待消毒」，登记药液批号、起止时刻、操作人、押运人：
    药液接触不足 10 分钟，或操作人与押运人相同，笼位继续停用；
    停用笼可重新登记消毒。
  - 消毒合格后进入「待复核」，次日复核合格才恢复「可用」，复核不合格继续停用。
  - 页面可按状态查询待消毒笼、可用笼位等，并按足环查询每鸽装鸽/换笼/卸鸽履历。

## 结构（三项职责分开）

- `src/turnover.js`：周转判定（状态规则、消毒合格判定、次日复核判定），纯函数。
- `src/store.js`：笼位档案与持久化（笼位状态、笼位事件、每鸽履历）。
- `src/page.js`：页面与交互（状态筛选、操作表单、履历时间线）。
- `server.js`：HTTP 路由，只做接线。
